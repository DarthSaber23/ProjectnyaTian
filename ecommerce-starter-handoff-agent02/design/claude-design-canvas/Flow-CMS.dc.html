Page states

DrafVisible only in admin and preview. TerjadwalPublishes automatically at the set time (Asia/Jakarta); can be cancelled back to Draf. TerbitLive and in sitemap.xml (if indexable). Terbit · ada perubahanLive version unchanged while edits sit in a draft revision; "Terbitkan perubahan" replaces it. Tidak terbitRemoved from the site; URL returns 404 or a chosen redirect; content kept.
Marketing, Admin and Owner may publish (D10). Every publish and unpublish is written to the audit log.

Validation before publish

  • Every block's required fields are filled; images have alternative text
  • URL slug unique, lower case, hyphens only
  • SEO title present (warning above 60 characters); meta description warning above 160
  • Campaign page linked to a promotion shows a warning if the promotion is not active in the scheduled period
  • Product blocks: hidden products are dropped with a warning, never shown as broken cards
  • Blog article: author, publish date and at least one category
Errors block publishing; warnings do not. The list links to the block that needs fixing.
