Scope classification

Essential = must work end-to-end in high fidelity (Claude Design + React prototype). Supporting = templated pages or admin wireframes. Future = not built; shown only as a clearly labelled "preview" where a seam is needed.

Essential

HI-FI + REACT
STOREFRONT

  • Catalog: categories, product grid, card variants, filters, sort, availability, badges, result counts, pagination

Prioritisation logic

Revenue path first. Discovery → PDP → cart → login → checkout → payment → order tracking is the spine; every other screen hangs off it.
Operate what you sell. Admin modules that change what the storefront shows (products, stock, orders, promotions, CMS) are essential; configuration screens are wireframes.
Prove reusability early. Homepage, catalog card and PDP are designed for both brands; shared flows (cart, checkout, account) are designed once and re-skinned by tokens.
