360 px checks (smallest)

Product card titles wrap to 2 lines, then truncate with full title in the accessible name. Price + strikethrough may wrap under each other; never shrink below 14 px. Checkout bottom bar: total stacks above the button if both don't fit. Variant chips wrap; no horizontal scrolling inside the purchase area.

Implementation notes (for M7)

Tailwind screens: sm 480, md 768, lg 1024, xl 1280, 2xl 1440. Brand composition config sets grid density and filter layout per breakpoint; shared components only react to container width where noted (product card, option cards). Sticky elements (header, purchase bar, checkout summary) never exceed 25% of viewport height.
