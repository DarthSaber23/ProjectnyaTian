Admin design rules

Theme: admin is brand-neutral chrome (greys from the Sambung token set) with the store's primary colour for actions; a Halimun fork swaps the primary token only. Density: 40 px controls, 14 px table text, tables in scroll boxes on tablet, stacked cards on phone (M3 responsive rules). Data: the same W00 dataset as the storefront. Admin numbers must equal storefront numbers (stock, prices, order totals). Privacy: customer contacts masked by default for Operations and CS; "Tampilkan" reveals are logged (D10). Audit: every status change, price, stock and promotion edit shows actor + time.
