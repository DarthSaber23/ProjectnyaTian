Product discovery flow

How visitors get from an entry point to a purchase decision. Every surface in column 2 can lead to every action in column 4 through the product detail page or a quick add.
1 · ENTRY
  • Homepage sections (S01)
  • Header menu / mega-menu
  • Search box (S04)
  • Campaign & blog links (S36, S35)
  • External: Google, social, ads, WhatsApp share → lands on any indexed page
  • Wishlist & recently viewed (S28)
→
2 · BROWSE
  • Category listing + filters + sort (S02, S03)
  • Search results (S05)
  • Collection page (S37)
  • Comparison (S08)
  • Recommendation strips on PDP, cart and homepage
→
3 · EVALUATE (PDP)
  • Variant → price, stock, images update
  • Shipping estimate entry (postal code)
  • Content blocks: benefits / ingredients (A), specs / compatibility (B)
  • Ratings & reviews (display, D8)
  • FAQ
→
4 · ACT
  • Add to cart → drawer (S09)
  • Wishlist → login if guest (I6)
  • Add to compare (max 4, same category — D2)
  • Bulk inquiry (S32)
  • Notify when back in stock — Future, shown disabled with label
Search pipeline (simulated, local dataset)
Type ≥ 2 characters
→
Wait 250 ms after last key
→
Normalise lower case, remove symbols
→
Synonyms "usb c" → "USB Type-C"
→
Typo tolerance 1 edit (≥4 letters), 2 edits (≥8)
→
Rank name > synonym > category > attribute
→
Show ≤ 6 products, ≤ 3 categories
Empty box focused: recent searches (stored on the device, clearable) and popular searches (editor-curated list).
Corrected query: results page says "Menampilkan hasil untuk "USB Type-C"" with a link to search the original words.
No results: spelling suggestion, popular categories, popular products, customer-service link. Failure: retry and browse categories.
Recommendation rules (hybrid, explainable)
Pilihan KamiEditorial: collections and lists curated in the CMS. Labelled as curated. Produk terkaitRule: same category, sharing ≥ 2 attribute values. Sering dibeli bersamaRule: complementary pairs set by admin on the product (cleanser → moisturiser; cable → adapter). Terakhir dilihatRule: last 10 products viewed on this device. Untuk AndaRule: categories of wishlist and past orders, excluding items already bought. Logged-in only; hidden if personalisation is off in S29.
Filter behaviour
  • Filters come from the category's attribute set: skin type, concern, size (A); length, connector, wattage, colour (B); price and availability for both.
  • Desktop: filters apply instantly. Mobile sheet: "Terapkan (24 produk)" button shows the live count.
  • Active filters appear as removable chips with "Hapus semua".
  • Options that would return 0 products are shown disabled with a count of 0, not hidden.
  • Sort: Relevan, Terbaru, Terlaris, Harga terendah, Harga tertinggi.
